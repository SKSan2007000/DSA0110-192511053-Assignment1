# Task 05 – Operators and Precedence

## Objective
To demonstrate arithmetic operators, operator precedence, increment operators, the conditional operator, division, modulus, and loop-based calculations in C++ using the Metro Smart-Card System assignment.

## Concepts Covered
- Arithmetic operators: `+`, `-`, `*`, `/`, `%`
- Operator precedence and expression evaluation
- Pre-increment (`++x`) and post-increment (`x++`)
- Conditional (ternary) operator (`?:`)
- Integer division and modulus
- `for` loop and compound assignment (`+=`)

## Program Description
The program evaluates arithmetic expressions to demonstrate operator precedence. It illustrates the difference between pre-increment and post-increment, uses a conditional operator to select a value, performs integer division and modulus operations, and calculates a total using a `for` loop.

## Expected Output
