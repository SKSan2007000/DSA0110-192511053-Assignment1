# Task02 – Execution Evidence

## Objective
To identify and demonstrate C++ tokens, keywords, identifiers, constants, operators, and separators using the Metro Smart-Card System.

## Execution Environment
- Platform: OnlineGDB
- Programming Language: C++
- Compiler: GCC 16.2.0, as reported by the environment

## Concepts Demonstrated
- **Keywords:** `enum`, `class`, `const`, `int`, `return`, `switch`, `case`
- **Identifiers:** `Zone`, `INNER_FARE`, `MIDDLE_FARE`, `OUTER_FARE`
- **Constants:** `1000`, `2000`, `3000` paise
- **Operators:** `=`, `<<`, `::`
- **Separators:** `;`, `{}`, `()`

## Expected Output

```text
METRO SMART-CARD SYSTEM
Task 02: Tokens, Keywords, Identifiers and Constants

Keywords: enum, class, const, int, return, switch, case
Identifiers: Zone, INNER_FARE, MIDDLE_FARE, OUTER_FARE
Constants: 1000, 2000, 3000 paise
Operators: =, <<, ::
Separators: ;, {, }, (, )

Inner Zone Fare: 1000 paise
Middle Zone Fare: 2000 paise
Outer Zone Fare: 3000 paise
```

## Result
The program compiled and executed successfully in OnlineGDB. It displayed the token categories and the fare constants for the Inner, Middle, and Outer zones.
