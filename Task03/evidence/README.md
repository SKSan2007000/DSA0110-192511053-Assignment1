# Task03 – Execution Evidence

## Objective
Demonstrate C++ data types, memory sizes, numeric limits, and type compatibility using the Metro Smart-Card System.

## Concepts Demonstrated
- Primitive data types and `sizeof`
- Integer limits using `INT_MAX` and `LLONG_MAX`
- `long long` for large journey and fare totals
- Arithmetic using integer values in paise

## Result
The program displays data type sizes and integer limits, then calculates the total fare for 3,000,000 journeys at 1,000 paise per journey.
